# SUPPA Pipeline

Scripts for running the
[SUPPA](https://github.com/comprna/SUPPA) alternative splicing
workflow.

## Contents
- `run_suppa.sh` – Example wrapper to quantify events
- `event_types.yaml` – Configuration of event types used in the analysis

## Usage
Edit the paths inside `run_suppa.sh` and submit it with `sbatch` or run
it directly on the command line.
