# Capybara Notebooks

Experiments using the Capybara tool for cell-type similarity and label transfer between datasets.

## Notebooks
- `build_capybara_ref.ipynb`, `capybara_refs.ipynb` - Construct reference matrices for Capybara
- `capybara_scores.ipynb` - Analysis of Capybara identity scores 
- `capybara_plots.ipynb` - Plotting code
