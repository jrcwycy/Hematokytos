# Benchmarking Reprogrammed Cells

Notebooks for analyzing bone marrow data, and benchmarking reprogrammed cells against native and engineered cell types.

## Notebooks

- `QC_bone_marrow.ipynb` – QC and filtering steps; expanded marker gene analysis for bone marrow cell types
- `bone_marrow.ipynb` – Marker gene expression for bone marrow cell types
- `BM_clusters.ipynb` – Expanded clustering and marker gene analysis for bone marrow cell types
- `BM_QC.ipynb` – Condensed marker gene analysis for bone marrow cell types (Figure S21)
- `benchmark_threelibraries.ipynb` – Distance analysis, DGE, and marker gene expression for control fibroblasts, reprogrammed, and bone marrow cells (Figures 4B-D, S22)
- `full_atlas.ipynb` – Overlapping cell types in the atlas; distance analyses (Figures 4E-H, S23, S24)
- `all_dataset_benchmarks.ipynb` – Benchmarking against external hematopoietic scRNAseq datasets (Figures 4I, S25)
