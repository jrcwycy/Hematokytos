# Results 2.4 Notebooks

Notebooks for analyzing bone marrow data, and benchmarking reprogrammed cells against native and engineered cell types.

## Notebooks
- `bone_marrow.ipynb` - Marker gene expression for bone marrow cell types
- `QC_bone_marrow.ipynb` - QC and filtering steps; expanded marker gene analysis for bone marrow cell types
- `BM_QC.ipynb` - Condensed marker gene analysis for bone marrow cell types
- `benchmark_threelibraries.ipynb` - Distance analysis, DGE, and marker gene expression for control fibroblasts, reprogrammed, and bone marrow cells
- `full_atlas.ipynb` - Overlapping cell types in the atlas; distance analyses
- `all_dataset_benchmarks.ipynb` - Benchmarking against external hematopoietic scRNAseq datasets
