# Reference Analysis Notebooks

Workflows for constructing and analysing the reference atlas used
throughout the project. They collect public hematopoietic datasets,
harmonize annotations and generate figures.

## Notebooks
- `build_reference.ipynb` – Generate the combined reference dataset
- `gather_hsc_data.ipynb` – Collect public HSC datasets
- `get_metadata.ipynb` – Retrieve and clean sample metadata
- `standardize_labels.ipynb` – Harmonise cell type annotations
- `summarize_obs.ipynb` – Summaries of reference cell populations
- `make_embedding.ipynb` – Compute UMAP/embedding for the atlas
- `cell_type_DEG.ipynb` – Differential expression across cell types
- `basename_DEG.ipynb` – Expression analysis by basename groups
- `native_atlas.ipynb` – Figure preparation notebook
- `summarize_sample_1.ipynb` – Additional sample-level summaries
